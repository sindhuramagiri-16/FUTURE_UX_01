# HOME & HUE

A modern interior design website UI created for Future Interns UI/UX Task 01.

## Project Overview

HOME & HUE is a conversion-focused interior design website designed to attract and convert potential customers through elegant UI and smooth UX. The website showcases a premium luxury aesthetic with warm, cozy tones perfect for an interior design business.

## Features

- **Modern Responsive UI** - Fully responsive design that works seamlessly on all devices
- **Soft Luxury Aesthetic** - Warm beige, cream, and brown color palette (#F7F2ED, #D8C3A5, #A47551, #3E2C23)
- **Premium Typography** - Playfair Display for headings, Poppins for body text
- **High-Quality Imagery** - Professional interior design photos from Unsplash
- **Lead Generation Focused** - Strategic CTAs and contact forms throughout
- **Smooth Navigation** - React Router implementation with seamless page transitions
- **Interactive Elements** - Hover effects, smooth transitions, and engaging animations

## Pages Designed

### 1. Homepage
- Hero section with full-width background image
- Services preview with image cards
- Why Choose Us statistics
- Portfolio gallery with masonry layout
- Client testimonials
- Final CTA section

### 2. Services Page
- Service cards with detailed descriptions
- Feature lists for each service
- Process timeline
- Consultation CTA

### 3. Contact Page
- Lead generation form with validation
- Trust elements (ratings, client count)
- Contact information
- Beautiful imagery

### 4. Shared Components
- Sticky navigation bar
- Professional footer with social links
- Consistent branding throughout

## Design System

### Colors
- Background: `#F7F2ED` (Warm Beige)
- Primary Beige: `#D8C3A5`
- Soft Brown: `#A47551`
- Dark Text: `#3E2C23`
- White: `#FFFFFF`

### Typography
- **Headings**: Playfair Display (Serif)
- **Body**: Poppins (Sans-serif)

### Spacing & Layout
- 16px border radius for cards
- Generous white space
- Consistent padding and margins
- Soft shadows for depth

## Tools & Technologies Used

- **React** - UI framework
- **TypeScript** - Type safety
- **Tailwind CSS v4** - Styling
- **React Router** - Navigation
- **Lucide React** - Icon library
- **Unsplash** - High-quality images
- **Vite** - Build tool

## Design Principles

1. **Premium Feel** - Luxury aesthetic without being ostentatious
2. **User-Centric** - Easy navigation and clear CTAs
3. **Conversion Optimized** - Strategic placement of consultation buttons
4. **Visual Hierarchy** - Clear content structure and flow
5. **Accessibility** - Proper contrast ratios and semantic HTML
